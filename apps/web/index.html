كلمة مرور التحقق بخطوتين

هذه كلمة مرور حساب تيليجرام الإضافية، وليست كلمة مرور لوحة الإدارة. تُستخدم في التحقق ولا تُحفظ.

اختيار قناة المحتوى

أدخل رابط قناة عامة مثل https://t.me/channelname أو @channelname أو المعرّف -100... لقناة يستطيع الحساب قراءتها. روابط الدعوة الخاصة لا تنضم للقناة تلقائيًا. لا يتم استيراد الرسائل القديمة تلقائيًا.

ابدأ بربط الحساب. يتم حفظ الجلسة مشفّرة بعد التأكد من صلاحية قراءة القناة.
خيار متقدم: إضافة المصدر بمعرّف القناة يدويًا
الخطوة 01 / TELEGRAM

إضافة قناة كمصدر

أنشئ مسارًا مرتبطًا بقناة محددة؛ يبقى معطلًا إلى حين التحقق.

الخطوة 02 / SOCIAL

إضافة حساب نشر

حدد الصفحة أو الحساب المهني المطلوب قبل إدخال بيانات الاتصال.

الخطوة 02 / ROUTING

ربط الحساب بالمسار

يمنع النظام اشتراك الحساب نفسه في مسارين متعارضين.

الخطوة 04 / SCHEDULE

جدولة النشر

الأيام: الإثنين=1 إلى الأحد=7. الأوقات بصيغة 24 ساعة.

ENCRYPTED CREDENTIALS

خزنة بيانات الربط

هذه البيانات لا تُحفَظ في المتصفح أو في المستودع. لا تعني تعبئة النموذج أن الحساب تم التحقق منه.

خيار متقدم: استيراد Telegram Session String موجودة مسبقًا
الخطوة 03 / TELEGRAM SESSION

جلسة تيليجرام

مخصصة لجلسة مصرّح بها مسبقًا. لا ننشئ رموز تحقق أو نسحب قنوات غير محددة.

الخطوة 03 / META ACCESS

رمز حساب Meta

احفظ رمز وصول مصرحًا به لصفحتك أو لحسابك المهني. التفعيل ينتظر فحص الصلاحيات.

INSTALLATION VAULT

تكامل Meta والتخزين السحابي

يمكن إضافة إعدادات التطبيق والتخزين من لوحة الإدارة. تُحفظ مشفّرة ولا تُعاد قيمها إلى المتصفح.

الإعدادات العامة / ENCRYPTED VAULT

إضافة أو تحديث إعداد محمي

حالة إعدادات التكامل

نتحقق من وجود القيمة دون كشفها أو السماح بقراءتها.

ملاحظة أمنية

يلزم توفير مفتاح تشفير عام للتثبيت عبر مدير أسرار الاستضافة. ولا نعرض أي قيمة سرية بعد حفظها. لا يتم تشغيل نشر حقيقي تلقائيًا عند حفظ البيانات.
